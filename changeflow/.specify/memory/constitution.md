# ChangeFlow Constitution
1. همه مجوزها و تغییر وضعیت‌ها سمت سرور بررسی شوند.
2. هیچ فردی حق تایید درخواست خودش را ندارد، حتی با داشتن دو نقش.
3. وضعیت Approved غیرقابل ویرایش است.
4. برای جلوگیری از بازنویسی تغییرات جدید، نسخه رکورد کنترل شود.
5. معماری ساده باشد و لایه اضافی نسازیم.
6. قوانین مهم تست شوند و نتیجه واقعی گزارش شود.
7. تصمیم نامشخص محصول باید به صورت فرض قابل بازبینی ثبت شود.
