# Analyze (بررسی دستی)
این گزارش خروجی دستور رسمی Spec Kit Analyze نیست، بلکه بررسی دستی سازگاری فایل‌هاست.
| Finding | اهمیت | تصمیم |
|---|---|---|
| احتمال بازنویسی تغییر جدید | زیاد | version و UPDATE شرطی اجباری شد |
| امکان تایید توسط درخواست‌دهنده با دو نقش | زیاد | شناسه صاحب با کاربر مقایسه شود |
| دسترسی فهرست مبهم | متوسط | Reviewer همه را می‌بیند، به صورت فرض موقت |
| لغو مجوز نامشخص | متوسط | خارج از نسخه اول؛ نیازمند تصمیم |
| تداخل تسک‌های موازی | کم | تسک موازی تعریف نشد |
