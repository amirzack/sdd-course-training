# جواب تمرین جلسه اول
### سوال ۱
پاس شدن تست‌ها دلیل نمیشه کد از نظر ساختار هم درست باشه. قانون جداسازی منطق بهتره تو قوانین اصلی پروژه باشه و موقع بررسی کد چکش کنیم.
### سوال ۲
نه، دستیار نباید خودش تصمیم بگیره مدیر درخواست خودش رو تایید کنه. فرض با تصمیم تایید شده فرق داره. معلوم نیست مدیر درخواست همه رو می‌بینه یا فقط تیم خودش و درخواست رد شده چطور دوباره ارسال میشه. باید سوال کنیم.
### سوال ۳
نیاز اینه که محتوای تغییر کرده بدون تایید دوباره اجرا نشه. شماره نسخه فقط یه راه حله. شاید بشه نسخه تایید شده رو نگه داشت که جا بیشتر می‌گیره یا از محتوا یه مقدار محاسبه کرد که دقت می‌خواد.
### سوال ۴
اول دیتابیس باید آماده بشه. دو کاری هم که همزمان یه فایل رو تغییر میدن ممکنه تداخل کنن. پوشش همه نیازمندی‌ها کافی نیست چون ترتیب کارها هم مهمه.
### سوال ۵
نه هنوز کامل نیست چون مشکل امنیتی باقی مونده. ساخت، تست، هماهنگی با نیاز و پذیرش نهایی فرق دارن. بررسی اولیه قبل از ساخت و بررسی نهایی بعدش انجام میشه. مشکل جدید باید اصلاح و دوباره بررسی بشه.
