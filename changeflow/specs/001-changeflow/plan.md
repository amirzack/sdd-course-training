# Plan
سه فایل اصلی داریم: app.js برای مسیرها و کنترل قواعد، store.js برای پایگاه داده و server.js برای اجرا. HTTP API کافی است و فرانت‌اند لازم نیست.
برای ذخیره از SQLite و برای تشخیص کاربر از توکن‌های آزمایشی استفاده می‌کنیم.
برای هم‌زمانی هر درخواست version دارد؛ UPDATE تنها وقتی اجرا می‌شود که id و version و status با نسخه فعلی برابر باشند.
محدوده فقط گردش درخواست است، نه مدیریت کاربر، اعلان، تاریخچه کامل یا امکانات هوش مصنوعی.
